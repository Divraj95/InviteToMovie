# A little invitation for you

A standalone movie-night invitation: open the heart seal, reveal the letter, and say yes for fireworks. The No button playfully shakes and displays a message.

## Preview
Open index.html in a browser. Everything is included in that file, with no dependencies or external assets.

## GitHub Pages
Create a public GitHub repository and upload index.html to its root. In Settings > Pages, choose Deploy from a branch, select main and / (root), then save. GitHub will display the published link once deployment finishes.

## Personalize
Edit the invitation and celebration text directly in index.html.

Responses stay in the browser; the website does not send you a notification when Yes is pressed.
